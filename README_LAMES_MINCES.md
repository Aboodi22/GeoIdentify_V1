# GeoIdentify : lames minces

Mode lame mince : 10 minéraux + 2 groupes. Toutes les questions sont posées (LPNA puis LPA), sauf si une observation décisive identifie le minéral (reste noir en LPA = grenat ; pléochroïsme N-S = tourmaline ; un seul clivage en lignes continues = mica) ou si la question ne s'applique pas.

## Couleurs proposées (LPNA)

Incolore, Gris / trouble, Jaune pâle, Rose pâle, Orange / rouge-brun, Brun, Vert, Bleu / bleu-vert

## Remarques

- Les valeurs sont simplifiées pour l'étude : vérifiez-les avec votre cours.
- Pléochroïsme : on suppose le polariseur E-W.
- Le tableau d'élimination en haut de chaque question montre : possible / douteux (1 contradiction) / écarté (2 contradictions ou plus).
